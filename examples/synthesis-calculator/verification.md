## Limits

This establishes a narrow working synthesis path at 7B, not reliability for arbitrary systems and not proof that 0.6B/1.5B can complete the task. No Unreal build/runtime environment, inheritance semantics, general invariant solver or Ability System adapter is included. Unsupported domain declarations are rejected explicitly instead of receiving a false Pass. Restarts create a new run from frozen DSL and current project baseline; they are not durable program-counter resumes.
