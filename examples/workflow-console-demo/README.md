# Пример консоли Workflow

Шесть нод: старт → создание файла → команда с живым выводом → проверка результата → подтверждение → завершение. Модель и интернет не нужны. Команда использует стандартные утилиты macOS/Linux: `sh`, `sleep`, `cat`, `grep`.

Откройте **Workflow → Tasks → Workflow Console Demo → Run**. В нижней панели **Console** появятся строки stdout с паузами по две секунды и отдельная диагностическая строка stderr. Нода **Watch live output** будет подсвечена; **Focus active** приблизит её. После команды нода **Review the console** будет ждать подтверждения: откройте **Run controls → Approve & continue**.

Результат — `demo-output.txt` в этой папке. Он содержит маркер `WORKFLOW-CONSOLE-DEMO-OK` и перезаписывается при следующем запуске. Для отдельной демонстрационной задачи выбран **Full access**, а ноды наследуют её настройку; другие задачи и проекты не меняются.

## Установка примера через API

1. `POST /projects` с `name: "Workflow Console Demo"` и `rootPath`, равным абсолютному пути к этой папке. Сохраните возвращённый `id`.
2. `POST /workflows` с содержимым `workflow.json`.
3. В `task.json` замените `__DEMO_PROJECT_ID__` на полученный `id` и отправьте результат в `POST /tasks`.

Адрес локального API совпадает с адресом открытого приложения. Все пути внутри workflow относительные, поэтому папку примера можно перенести и зарегистрировать как отдельный проект. Файлы JSON сами по себе не запускают workflow.
