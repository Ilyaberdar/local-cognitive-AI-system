# Local Cognitive

Release files and update feeds for [Local Cognitive](https://local-cognitive.com), a private AI workspace: chats, agents, workflows and Synthesis with models on your own computer or your own GPU server.

The source code is not published here.

## Download

Get the app from [local-cognitive.com](https://local-cognitive.com) or from the [latest release](https://github.com/Ilyaberdar/local-cognitive-AI-system/releases/latest):

- macOS (Apple silicon): `Local-Cognitive-<version>-arm64-mac.dmg`
- Windows: `Local-Cognitive-Setup-<version>.exe`
- Linux GPU server:

  ```sh
  curl -fsSL https://github.com/Ilyaberdar/local-cognitive-AI-system/releases/latest/download/install.sh | sudo bash
  ```

Each release lists SHA-256 checksums in `SHA256SUMS`.
